# テンプレートの判断の記録

テンプレートの今の形について、なぜそうしたか・前提・とらなかった案を書く。
テンプレートのファイルを変える前に関係するノートを読み、判断を変えたら同じ PR でノートも直す。

## 何をどこに書くか

| 書くこと | 置き場所 |
| --- | --- |
| 使う側がそのファイルを正しく使う・直すために要る理由 | そのファイル（コメントや本文）。使う側にも写る |
| テンプレートの作りを変えるときだけ要る理由（なぜこの形にしたか、前提、とらなかった案） | このフォルダ |
| その PR でなぜ変えたか（経緯） | PR の本文（Squash merge なので main のコミットメッセージになる）。`git log -- <パス>` でたどる |

- 書くのは、今も効いている判断だけ。判断を変えたら、古い理由は消して書き換える（経緯は PR に残っている）
- 1つの判断は1か所にだけ書く。ほかのノートからは見出しで指す
- 確かめ待ちのものは「決まっていないこと」に書き、決まったら移すか消す
- 下の一覧にないファイルの判断を書くときは、合うノートに足すか、新しいノートを作って一覧に足す
